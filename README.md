# Должник (The Debtor): хоррор-мод для Minecraft 1.20.1 (Fabric)

Мир ничего не даёт бесплатно. Каждое действие записывается в скрытый долговой счёт.
Счёт нигде не показывается, о нём можно судить только по косвенным признакам.

## Вес действий
| Действие | Долг |
|---|---|
| земля / камень | ~1 / ~2 |
| уголь, медь / железо / золото | 4 / 8 / 12 |
| алмаз, изумруд / древний обломок | 25 / 40 |
| бревно | 6 |
| обычный моб | 0.5–1.2 × здоровье |
| деревенский житель / железный голем | 40 / 30 |
| эндермен / иссушитель / варден / дракон | 15 / 400 / 300 / 500 |
| огниво, огненный шар, лава | 5 |

Долг очень медленно сам спадает (0.6 в минуту). Посадка саженца даёт −2.5.
Креатив и спектатор долга не копят.

## Стадии (пороги: 250 / 900 / 2500 / 5000)
1. **Первые знаки**: ночью выкопанные тобой шахты зарастают блоками, которых ты не ставил (только пока не смотришь). Шаги раздаются через долю секунды после твоих, но позади тебя.
2. **Изъятие**: из сундуков пропадают предметы, которые ты добыл (чаще в чанках, где копал больше всего); факелы в твоих тоннелях гаснут сами; на месте срубленных деревьев вырастают чёрные стволы, неломаемые, пока ты не смотришь; издалека доносятся удары кирки в старых тоннелях.
3. **Взыскание**: мир начинает ломать твой дом (вокруг точки возрождения, то есть кровати) и сундуки, пока ты не смотришь. Появляется Кредитор. Пока на него смотришь, он замер. Отвернулся, он приближается. Если обернуться, когда он близко, он исчезает, а на экране темнеет. Шаги за спиной слышны даже когда ты стоишь.
4. **Расчёт**: Кредитор идёт быстрее. Дом и сундуки ломаются всё быстрее и открыто, сундуки пропадают вместе с содержимым. Если Кредитор дотронется, он заберёт 3 предмета и ударит, но долг НЕ спишет. Убить его нельзя.

## Сборка
Нужны JDK 17 и Gradle 8.x.

    gradle wrapper --gradle-version 8.5
    ./gradlew build          # jar: build/libs/dolzhnik-1.0.0.jar
    ./gradlew runClient      # запуск для теста

Положи jar в `mods/` вместе с Fabric Loader 0.14.24+ и Fabric API для 1.20.1.

## Тестирование
Команды для операторов: `/debt get <игрок>`, `/debt set <игрок> <число>`, `/debt add <игрок> <число>`.
Быстрая проверка стадии 3: `/debt set @s 2600`, потом найди открытое место. Кредитора можно позвать и вручную: `/summon dolzhnik:creditor`.
Чёрный ствол: `/give @s dolzhnik:black_trunk` (в креативе ломается).
